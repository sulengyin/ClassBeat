# ClassBeat · 班级节律屏

教室里那块大屏，整天只做一件事：告诉学生**现在该干什么**。

上课、课间、午餐、午间、放学，23 个作息块自动切换，不用老师按遥控器。
课间写「喝水 · 上厕所」和「准备好：语文书 · 练习本」，上课写第几节、谁教，
到点写「还有 3 分钟」。老师还能从手机上推一句话上屏。

时间一律按**北京时间**显示，设备时区设错也不会偏；同一局域网有消息服务时还会顺手校一次时钟。

它不打卡、不记分、不排名。**只用来看时间该干什么。**

---

## 下载试用

不用装 Python，也不用命令行：

1. 打开 [Releases](https://github.com/sulengyin/ClassBeat/releases/latest)，下载 `classbeat-0.2.0.zip`（之后的版本文件名里的版本号会跟着变）；
2. 解压到任意文件夹，比如桌面；
3. 双击里面的 `打开大屏.bat`，浏览器会自动打开大屏。

只想先看看长什么样：下载同一个页面上的 `classbeat-0.2.0-single.html`，双击就能开，不用解压。

包里是**示例班级**（示例小学 · 五（1）班 · 张老师），不是真实学生。打开后点右下角「⋯」→ 编辑，改成自己的班即可；改完**不要把自己的文件夹发给别人**，要分享请发原始下载包。

## 现在能做什么

| | |
|---|---|
| **按时段自动切换** | 23 个作息块 + 7 条课间，按分钟切换，倒计时可配 |
| **晨间自主管理 + 提醒事项** | 晨间自主管理 07:30–08:10，标题写「英语学习建议」这类科目建议；老师填的那条建议在标题下一行，同字号大字；黄色贴纸单独放「提醒事项」 |
| **课前准备提前** | 8:10 晨间自主管理一下课，第一节课要带的用品立刻上屏；上课期间不占屏 |
| **岗位提醒** | 18 个班级岗位，到点提醒该谁做事，频率分 7 类 |
| **值日轮岗** | A/B 组按周轮流，起始周可设；放假自动跳过，整周停课不消耗轮次 |
| **两行课间提示** | 第一行「现在做什么」，第二行「准备好：带什么」 |
| **早晚变色** | 底色跟着天光走，从清晨暖色到傍晚偏暗，不按科目跳色 |
| **北京时间** | 不依赖设备时区；局域网服务可达时自动校时 |
| **手机推消息** | 大屏出二维码，手机扫一下就发；一句话上屏，可设时长、可撤回 |
| **整屏可改** | 验证码进入编辑态，改文字、改今天、换人、调课、调作息，改动只在本机 |

深色模式是纯黑底白字，给拉窗帘的教室用。

## 目录

```
app/        大屏本体（页面本身不带数据，要先跑 bundle.py 生成 data.js）
server/     局域网消息服务（Python，可选）
tools/      构建 / 校验 / 测试 / 打包
sample/     示例班级数据（化名，公开仓库用这份）
data/       你自己的班级数据（不入库）
docs/       说明与决策记录
```

`docs/PLAN.md` 是设计与取舍的完整记录（含阶段计划、未做项和每次真机反馈）。

## 先跑起来

需要一个 Python 3（只用标准库）和 Node（跑前端测试时才需要）。

```bash
git clone <this-repo> ClassBeat
cd ClassBeat

# 用示例班级生成数据（公开仓库不含真实班级数据）
python3 tools/bundle.py --data sample

# 直接打开
open app/index.html          # macOS
start app\index.html         # Windows
```

想验证一切正常：

```bash
node tools/test_rhythm.js    # 节律逻辑
node tools/test_clock.js     # 北京时间与校时
node tools/test_store.js     # 本地存储
node tools/test_dom.js       # 页面起得来、不白屏
python3 tools/check_p1.py    # 数据自洽
python3 tools/test_calendar.py # 校历与值日轮岗
python3 tools/test_server.py # 消息服务
```

## 换成你自己的班

**老师拿到包**：解压，双击「打开大屏.bat」。首次打开检测到还没配过班，会自动进配置向导——填班级名、选一套作息模板、排 5 天 × 7 节课表、改岗位和文案。四步都能跳过，改完立刻生效，全程不用命令行。

配好一台后，点「导出设置 JSON」；另一台电脑在同一页点「导入设置 JSON」，班级、作息、课表、文案一起搬过去。岗位表和作息表也可以直接从 Excel / Word 里粘表格。

**改数据文件**（开发者或批量调整）：数据是纯 JSON，没有数据库。改 `data/` 里这七个文件，再 `python3 tools/bundle.py`：

| 文件 | 管什么 |
|---|---|
| `timetable.json` | 作息：几点到几点、什么类型（晨间自主管理/正课/课间/午餐/午间） |
| `schedule.json` | 课表：周几第几节、什么科目、谁教 |
| `roles.json` | 岗位：擦黑板、路队长、节能小队长…谁负责、多久一次 |
| `students.json` | 名单：只用于编辑时补全和换人 |
| `content.json` | 每科要带什么 |
| `texts.json` | 屏上文字：晨间自主管理的科目与建议、提醒事项、各时段提示语、每科清单（可选，会烤进包） |
| `noon.json` | 午间那几个可调的分界点 |
| `calendar.json` | 校历：只写例外——哪天放假、哪天调休上课 |

先把 `sample/` 拷成 `data/`，再逐条改：

```bash
cp -r sample data
```

两条硬规则：

1. **课表不存时间**，时间只来自作息表。调一次作息，全周跟着变。
2. **没写的就留空**。`unset` 不上屏，宁可少显示，也不猜一个错的值。

`python3 tools/bundle.py` 生成的是**配置包**，不生成任何一天。当天的课表由
`app/engine/schedule.js` 在浏览器里按作息和课表现算，所以它不会「过期」，
不需要每周重跑；只有改了 `data/` 里的文件才需要重新 bundle 一次。

临时调作息不必改文件：大屏上「⋯」→ 编辑 → 作息，改时间、加一段课间、删一段，
确定后立刻生效，并且只影响这台机器（可以在编辑页导出成 JSON 带走）。

### 值日轮岗怎么算

`roles.json` 里的 `dutyCycle` 管 A/B 组什么时候换：

```json
"dutyCycle": {
  "groups": ["A", "B"],
  "anchor": "2026-08-31",    // 起始周的周一
  "anchorGroup": "A",        // 这一周轮到哪组
  "status": "confirmed"      // 没确认就输出 unknown，不猜
}
```

轮次按**上学的周**数，不按日历周数：

| 情况 | 结果 |
|---|---|
| 周一放假，周二到周五上课 | 这一周照常算一周，周日照做，下周一换组 |
| 整周放假（国庆、停课） | **不消耗轮次**，回来还是原来那组 |
| 只放一天（周三秋游） | 不影响轮换，只是那天不上学 |
| 调休周六上课 | 算上学日，按 `calendar.json` 里的 `asWeekday` 取课表 |

`calendar.json` 只写例外，没写的日子默认周一到周五上课：

```json
"days": {
  "2026-10-01": { "kind": "holiday", "name": "国庆节" },
  "2026-10-10": { "kind": "school", "name": "调休上课", "asWeekday": 5 }
}
```

## 备份

公开仓库里只有代码。`data/`、`assets/`、`PLAN.md` 都在 `.gitignore` 里，
**只 clone 仓库等于什么都没备**。真要备份的是这几样：

```bash
python3 tools/backup.py
```

生成 `backups/ClassBeat-备份-YYYYMMDD-HHMM.zip`，里面是：班级数据、原始表照片、
本地文档、当前安装包、`MANIFEST.txt`（逐文件 SHA256），外加一个 `git bundle`
（完整提交历史，`git clone xxx.bundle ClassBeat` 就能离线还原）。

大屏自己也会留底，不用点按钮：从本机服务打开（`打开大屏.bat`）时，配置改动后
一分钟内写到 `backups/config/rhythm-YYYY-MM-DD.json`，一天一份，留最近 14 天。
换电脑或换地址后，进编辑页「带走这些修改 → 本机自动备份」，按日期点「恢复」。
这个目录里有真实班名和名册，**不要单独转发**；给别人发原始安装包即可。
双击 `app/index.html`（`file://`）时没有服务可写盘，只会在浏览器里留一份副本；
一个月没导出过设置时，编辑面板会提示并给一个「现在导出一份」按钮（不弹窗）。

## 测试

三层，各管一件事：

| 层 | 命令 | 管什么 |
|---|---|---|
| 逻辑 | `node tools/test_rhythm.js` 等 | 时段判断、岗位、存储、校时、消息服务、端口顺延、配置模板与导入导出，502 项，秒级 |
| 引擎对拍 | `node tools/test_engine.js` | `app/engine/schedule.js` 与 Python 编译器 132 天逐字段一致（基准在 `tools/golden/`） |
| 换学校 | `python3 tools/test_variants.py` | 4 套作息 × 5 套岗位 × 4 份校历 = 80 套配置，每套连编 70 天 |
| 真浏览器 | `npx playwright test` | 21 个用例 / 7 个视口项目：一体机 1920/1366、iPad、iPhone、iPhone SE、安卓、鸿蒙视口 |

换学校那一层不去猜「真实学校长什么样」，而是程序化生成不同作息（8:00/8:20/8:30 上课、
35/40/45 分钟一节、有无课后服务、短课间），配上不同岗位与校历，逐套检查：
不崩、时间线首尾相接、用到的人名都在名单里、说不清的岗位输出 unknown、
值日时刻落在到校与离校之间。

真浏览器那层跑的是**同一份代码、同一台消息服务**，只是把视口和内核换掉：

```bash
npm ci
npx playwright install chromium webkit
python3 tools/bundle.py --data sample
npx playwright test
```

里面有两条是专门为大屏写的：一条把时间钉在 17:12 看值日条出不出来，
一条把时钟从 06:30 快进到 18:30 连跑 12 小时，看节点数会不会一路涨。

这三层都在 GitHub Actions 的虚拟机上跑，每次推送自动执行。它抓到的第一批问题都不是逻辑错，
是"在某一种屏上不成立"：深色底色被 CSS 变量别名吃掉、手机输入框字号掉到 13px（iOS 一聚焦就放大整页）、
工具条在触屏上默认点不到（`pointer-events:none` 要先进齿轮）。

报告怎么看：Actions 里每次运行都会附一份 HTML 报告（artifact，保留 7 天，含截图、录像、trace）。
另外 `tools/e2e/summary.js` 会把结果压成一条汇总加若干条 annotations：
**失败**是 error、**重试才过**是 warning、**跳过**计数进汇总。
后者不用登录也能从 Actions 页面或 check-run API 读到，适合先扫一眼“红的是哪一条”。

**没覆盖的**：真机（鸿蒙 ArkWeb、教室一体机）的渲染差异、触屏手感、反光和字号观感。
`鸿蒙` 这个项目是 Chromium 加鸿蒙 UA 加 360×780 视口，能挡布局和触摸尺寸问题，
挡不住内核差异——别把它当成真机结论。

## 手机推消息

服务和大屏分开跑，大屏不需要装任何东西：

```bash
python3 server/run.py          # 守护模式：崩了自动拉起，已经在跑就不再开第二个
python3 server/rhythm_server.py --port 8765   # 直接跑，排错时看输出用这个
```

打包给老师的版本里双击「启动手机服务.bat」即可：走 `pythonw` 无窗口启动，
日志落在 `server/server.log`，停止用「停止手机服务.bat」。
8765 被别的软件占了会自动顺延到 8766、8767…（最多到 8774），
大屏从 8765 起挨个问，找到就切过去，不用改地址。

手机连同一个 WiFi，打开 `http://<电脑IP>:8765`。
不想抄 IP 就点大屏右下角「⋯」→「手机」：屏上出二维码，手机扫一下直接进发送页；
面板上还有「复制地址」，可以把这条链接存进钉钉群或收藏，以后点一下就到。
这个码由 `app/vendor/` 里的 MIT 库在本地生成，不联网、不请求第三方服务。

电脑重启后地址一般不变；哪天变了，面板会提示上次的地址，点「复制地址」重新发一次即可。
要长期不变，请网管按 MAC 做 DHCP 保留（比手工静态 IP 稳，详见 `ROADMAP.md` 阶段 4）。

消息可以设 5 档时长，也可以不自动关、由老师长按撤回。

学生留言功能暂未实现——它不是技术问题，是隐私问题，要先想清楚谁能看见。

## 隐私

这个仓库**不含任何真实学生姓名**。

- `data/` 与 `assets/` 在 `.gitignore` 里，真实名册和学校素材照片不会入库。
- 自动备份的 `backups/config/` 同样在 `.gitignore` 里；它含真实班名与名册，别单独转发。
- `sample/` 是 `tools/make_sample.py` 从真实结构生成的**化名**版本：48 个编造的学生名、
  「张老师」这类化名、示例小学、五（1）班。结构完全一致，可以直接拿来演示。
- `tools/make_sample.py --check` 会扫一遍 `sample/`，确认没有一个真实姓名漏进去。
- 大屏数据全部在浏览器本地存储里，不上传、不联网。

## 现状

`v0.2.0`（当前发布版）：配置会自动留底，换地址或换电脑也能按日期恢复；配置向导已经落地，别的老师不用碰命令行就能配出自己的班。

拿到包解压双击，第一次打开会自动进向导：班级 → 作息模板 → 5×7 课表 → 岗位和文案。岗位表、作息表、课表都能从 Excel / Word 里粘；配好可导出 JSON 搬到另一台电脑。完整包与单文件版都挂在 [Releases](https://github.com/sulengyin/ClassBeat/releases) 上，由 `.github/workflows/release.yml` 在打标签时自动构建。这个包已经在教室的 Windows 机器上实际跑过，可以正常使用。

**还没做的**：向导的真机 10 分钟验收（代码与 e2e 已过，等教室一体机上走一遍）；P4 要求在真实班级连续跑满两周，仍在进行。P3 的「角色区分（学生只读 / 看护老师仅当天）」也还没做，依赖对使用场景的进一步确认。

**手机消息已经不需要装 Python 了**：`tools/package.py` 会把官方免安装运行时
（Python 3.12 embeddable，约 11 MB）打进 `server/python/`，一体机双击就跑，
不安装、不改 PATH、不需要管理员权限。代价是包从 160 KB 变成约 11 MB；
只想看大屏的话用单文件版，约 420 KB。

**从源码跑的人**（没有用发布包）需要先生成数据文件：

```
python3 tools/bundle.py --data sample
```

再打开 `app/index.html`；直接双击会因为没有 `app/data.js` 而只看到空页面。
