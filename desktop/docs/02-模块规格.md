# 02 · 模块规格（Rust 壳）

技术栈：**Tauri 2 + Rust 2021**。窗口/托盘/单实例用官方 API，注册表与热键用 `windows` crate，
不引第三方日志、HTTP、对话框库（依赖越少，杀软误报与升级断裂越少）。

> 参考实现在 `../src-tauri/src/`（0.4.0 起已编译、已装真机验证），可直接用，也可整段重写——
> 本文的接口与行为约束才是契约。
>
> 📌 0.5.0 起服务是 `classbeat-server.exe`（`../server-rs`），不再是 `pythonw.exe`；
> 本文已按现状同步，`src-tauri/resources/python` 相关的描述全部作废。

## 2.0 全局约束

| 约束 | 原因 |
|---|---|
| `main.rs` 必须有 `#![cfg_attr(all(not(debug_assertions), target_os="windows"), windows_subsystem="windows")]` | release 下否则会多一个控制台窗口 |
| 起服务程序必须 `creation_flags(CREATE_NO_WINDOW)` 且 `stdin/stdout/stderr` 全 `Stdio::null()` | 黑窗 = 本次重构第一目标 |
| 任何窗口创建都要 `app.run_on_main_thread(...)` | 服务就绪发生在后台线程 |
| 退出只有一条路径：`shutdown(app)` | 先把服务进程杀掉再 `app.exit`，避免孤儿进程 |
| 日志不得写进安装目录 | perMachine 时 Program Files 只读 |

## 2.1 `config.rs` — 路径与常量

```rust
pub const APP_NAME: &str = "ClassBeat";
pub const KIOSK_TITLE: &str = "班级节律屏";   // 必须含这五个字，见 04 §4.5
pub const DEFAULT_PORT: u16 = 8765;
pub const PORT_SPAN: u16 = 10;
pub const EXIT_FLAG: &str = "exit-request.flag";

pub struct Paths {
    pub install_root: PathBuf, // 含 app/ 与 server/ 的目录（resources）
    pub data: PathBuf,         // %APPDATA%\ClassBeat
    pub logs: PathBuf,         // data/logs
    pub legacy: PathBuf,       // %LOCALAPPDATA%\ClassBeat（0.3.x 旧安装）
}
```

要点：

- `discover(resource_dir)` 要**容错两种 resources 布局**：`<res>/app` 与 `<res>/resources/app`，谁有 `app/index.html` 用谁。
- `CLASSBEAT_DATA_DIR` 环境变量优先（测试与开发用）。
- `pick_port()`：8765→8774 逐个 `TcpListener::bind` 试，成功即返回；全失败回 8765，让服务自己顺延。

## 2.2 `logging.rs` — 一个文件、1MB 轮转、北京时间

```rust
pub fn init(dir: &Path) -> std::io::Result<()>;
pub fn info(msg: &str); pub fn warn(msg: &str); pub fn error(msg: &str);
```

- 路径 `data/logs/app.log`，超 1MB 改名为 `app.log.1`（只留一份）。
- `init` 里挂 `std::panic::set_hook`，panic 也落盘。
- 时间戳不引 chrono：UTC 秒 + 8 小时，用 civil-from-days 转年月日（约 15 行，有单测）。
- 老师只需要发一个文件，所以**不要**再产出第二个日志文件。

## 2.3 `server.rs` — 起服务、查健康、挂了重启

```rust
pub struct ServerState { child: Mutex<Option<Child>>, stopping: AtomicBool }
impl ServerState { pub fn is_running(&self) -> bool }

pub fn boot(app: AppHandle);      // 后台线程：等 8 秒(自启) → start → open_screen → supervise
pub fn stop(app: &AppHandle);     // stopping=true + kill child + wait
```

`start(app) -> Result<u16, String>`：

1. 取服务程序：`CLASSBEAT_SERVER` 环境变量优先，否则 `server_dir/classbeat-server.exe`；不存在直接返回可读错误（提示先跑 `classbeat-tools stage`）。
2. `pick_port()` → 起进程，参数 `--port <p> --host 0.0.0.0`，`current_dir = server_dir`。
3. 环境变量：只设 `CLASSBEAT_DATA_DIR=<data>`。壳模式、静态根目录都是服务自己的原生行为，不需要 `CLASSBEAT_SHELL` 之类的开关。
4. 健康等待：25 秒内每 250ms 打一次 `GET /api/ping`（手写 HTTP/1.0，不引 reqwest），**必须**同时满足：状态行含 `200`、body 含 `classbeat`。成功后解析 `"port": N` 作为真实端口（可能因顺延与入参不同）。

`supervise(app, port)`：

- 每 5 秒 ping 一次；连续 3 次失败 → `kill_child` → 重新 `start`。
- 重启失败：退避 1→2→4…最多 30 秒，无限重试（课堂不能因为一次失败就永久黑屏）。
- 每轮先检查 `quitting` / `stopping` 再决定是否继续。

**失败处理**：`start` 失败不 panic，走 `window::show_error(app, &e)`，窗口里显示原因 + 日志路径。

## 2.4 `window.rs` — 三个窗口 + 误关保护

```rust
pub fn open_screen(app: &AppHandle, port: u16);   // 主线程创建，已存在则 show+unminimize+focus
pub fn show_or_open(app: &AppHandle);             // 托盘/二次启动；port==0 时只记日志
pub fn open_phone(app: &AppHandle);               // 430×760 普通窗口，加载 /phone
pub fn show_error(app: &AppHandle, msg: &str);    // 加载 web/index.html?msg=...
pub fn minimize_screen(app: &AppHandle);
```

大屏窗口参数（一个都不能少）：

| 参数 | 值 | 原因 |
|---|---|---|
| title | `KIOSK_TITLE` | 页面的「最小化/退出」靠标题找窗口（04 §4.5） |
| url | `WebviewUrl::External("http://127.0.0.1:<port>/screen")` | 保证 origin 与旧版一致，localStorage 语义不乱 |
| decorations | false | 无标题栏 |
| fullscreen | true | 全屏，替代 Chrome `--kiosk` |
| always_on_top | true | 压住任务栏/其他窗口 |
| resizable | false | 防误拖 |

**关窗语义（替代 watchdog 的"误关拉起"）**：

```
CloseRequested → prevent_close()
   ├─ quitting 为真 或 <data>/exit-request.flag 存在 → 删标记 → shutdown(app)   // 老师主动退出
   └─ 否则 → hide()                                                          // 误触，收进托盘
```

## 2.5 `tray.rs` — 老师感知到"这是个应用"的入口

菜单项（顺序固定）：打开大屏 / 手机控制页… / ── / 检查更新… / 重启后台服务 / 打开日志目录 / ── / 退出 ClassBeat。

- 图标用 `Image::from_bytes(include_bytes!("../icons/classbeat.ico"))`，需开 `image-ico` feature。
- 左键点图标弹菜单（`show_menu_on_left_click(true)`）。
- 退出前 `ui::confirm`；更新中（`update::is_busy()`）拒绝退出并提示。
- 无更新器构建时"检查更新"置灰（`cfg!(feature="updater")`）。

## 2.6 `hotkey.rs` — 逃生门

`RegisterHotKey` + 自建消息循环（不用插件）：

| 热键 | 行为 |
|---|---|
| `Ctrl+Alt+Q` | 确认后退出应用 |
| `Ctrl+Alt+M` | 最小化大屏（临时看桌面） |
| `Ctrl+Alt+U` | 检查更新 |

注册失败（被占用）只记 `warn`，托盘菜单仍可用——**绝不能因为热键失败就影响大屏**。

## 2.7 `power.rs` — 防休眠

线程内每 30 秒 `SetThreadExecutionState(ES_CONTINUOUS|ES_DISPLAY_REQUIRED|ES_SYSTEM_REQUIRED)`。

## 2.8 `autostart.rs` — 注册表 Run（不写启动文件夹）

```rust
pub fn is_enabled() -> bool;      // reg query 成功即 true
pub fn enable() -> Result<(), String>;   // reg add ... /d "\"<exe>\" --autostart" /f
pub fn disable() -> Result<(), String>;
pub fn ensure_enabled();          // 启动时幂等补齐，失败只 warn
```

为什么不用启动文件夹：旧方案那个 `.lnk` 被清理工具删掉后无法感知，注册表项卸载器能精确删除。

## 2.9 `migrate.rs` — 旧数据二道保险

- 判定旧安装必须够窄：`legacy/tools/launcher/watchdog.ps1` 或 `legacy/server/python/python.exe` 存在。
- 复制 `data/`、`backups/`、`update-source.txt` 到新数据目录，**目标已存在则跳过**（绝不覆盖），遇到 `app/server/tools/python` 目录直接跳过。
- 纯复制，不删除（删除由安装器的 PREINSTALL 做）。
- 必须有单测：给定旧目录结构，验证只搬了 data、没搬程序文件。

## 2.10 `update.rs` — 签名更新（feature `updater`，默认开）

```rust
pub fn is_busy() -> bool;
pub fn check_interactive(app: &AppHandle);        // 弹框确认 → 下载安装
pub fn check_quiet_after(app: AppHandle, secs: u64); // 启动后静默查一次，只写日志
```

- 用 `tauri_plugin_updater`（`UpdaterExt::updater()` → `check() → Option<Update>` → `download_and_install`）。
- 下载/安装失败：日志 + 弹框，**不能让大屏崩**。
- 未配置公钥时（占位符）只提示"更新器不可用"，不影响其它功能。

## 2.11 `ui.rs` — 原生小交互

`info / warn / confirm(title,text) -> bool`（`MessageBoxW`，带 `MB_TOPMOST|MB_SETFOREGROUND`），`open_folder(path)`，`open_url(url)`。

## 2.12 `commands.rs` — 预留 IPC

`app_status`（版本/端口/数据目录/服务是否在跑）、`restart_server`、`open_screen_window`、`open_phone`、`open_logs`、`quit_app`。
页面目前不调 IPC（全部走本地 HTTP），这些命令留给未来的设置窗口与调试。

## 2.13 `lib.rs` — 编排

启动顺序（顺序错了会白屏）：

```
解析 --autostart → 建 Paths → ensure 目录 → init 日志 → manage(AppState)
→ autostart::ensure_enabled()（非自启时）
→ power::keep_awake() → migrate::run_at_startup() → tray::install() → hotkey::install()
→ server::boot()（后台线程，不阻塞 setup）
→ 服务 ping 通后 window::open_screen()
```

单实例插件回调：`window::show_or_open(app)`（二次双击不开第二个）。

`shutdown(app)`：`begin_quit()` → `server::stop()` → `app.exit(0)`，必须幂等（`is_quitting` 早退）。
