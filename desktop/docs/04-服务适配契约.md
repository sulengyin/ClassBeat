# 04 · 服务适配契约（Python 侧）

壳不改业务代码，但对 `server/` 提了 **3 个环境变量**、**1 处行为变更**、**6 处定点补丁**。

铁律：这些改动只做在**构建时的副本**上（`src-tauri/resources/server/`），仓库里的 `server/` 一个字节不动；
不改就完全等于旧行为 —— 单文件版、解压版、现有 400+ 条测试全部照旧。

## 4.1 三个环境变量

| 变量 | 值 | 作用 | 不设时 |
|---|---|---|---|
| `CLASSBEAT_DATA_DIR` | `%APPDATA%\ClassBeat` | `messages.json`、`net.json`、`server.log`、`backups/config/`、remote 待办文件改落这里 | 一切照旧（写在包内） |
| `CLASSBEAT_SHELL` | `1` | 跳过 `watchdog_handover()`；`/api/update/status` 报 `selfUpdate:false`；「退出大屏」走壳内退出 | 旧行为 |
| `PYTHONDONTWRITEBYTECODE` | `1` | 不许写 `__pycache__`（perMachine 时程序目录只读） | 无所谓 |

`/api/ping` 额外返回 `"shell": true`，冒烟测试与诊断靠它区分形态。

## 4.3 装配脚本的锚点策略（重要）

补丁以"锚点原文 → 替换文本"的形式在副本上执行，规则：

1. 每个补丁带一个**幂等哨兵**（只出现在替换后文本里的短串，例如 `def _data_file(name):`）。
   哨兵命中 → 跳过（已适配）。
2. 锚点未命中 → **直接失败退出**并打印锚点首行，绝不产出半成品包。
3. 锚点命中多次（>1）→ 也失败（说明上游结构变了）。

> 踩过的坑：不要用锚点首行（`HOME_ID = home_id()`）当幂等判据，
> 它在替换前后都存在，会误判"已适配"从而跳过补丁，结果服务 import 就 NameError。

## 4.4 一处行为变更：程序内更新

| | 旧 | 新 |
|---|---|---|
| 谁更新程序 | `server/updater.py`（下载 zip → 替换 app/、server/ → 健康检查 → 回滚） | `tauri-plugin-updater`（minisign 签名 → NSIS 被动安装） |
| 页面表现 | 「⋯ → 更新」检查/安装/回滚 | 同位置显示"桌面版由 ClassBeat 应用统一更新：点托盘 → 检查更新（Ctrl+Alt+U）" |
| 数据 | 不参与更新 | 不参与更新（一致） |

原因：perMachine 装进 Program Files 后程序目录不可写；且两套更新器互不认识对方产物，
同跑必然版本错位（0.3.x 的 2.58「跨代自愈」就是在跟这个问题打仗）。

**能力没丢，路径变了。** `updater.py` 不删——单文件版/解压版继续用它。
前端无需改动：`app/update.js` 已经有 `selfUpdate === false` + `blockedReason` 的渲染分支（0.3.17 就为单文件版写了）。

## 4.5 为什么窗口控制没换成 IPC

页面「最小化 / 退出大屏」调 `/api/screen/minimize`、`/api/screen/exit`，
服务端**按窗口标题枚举**找大屏窗口（`KIOSK_TITLE_MARK = "班级节律屏"`）。

壳把窗口标题固定写成 `班级节律屏`，这条链路就原样可用，`app/` 里一行 JS 都不改。
代价是判据依赖标题；收益是零改动、零回归。

要换 IPC 时的顺序（别跳步）：

1. 壳加 `screen_minimize` / `screen_exit` 命令；
2. 页面在 `window.__TAURI_INTERNALS__` 存在时走 IPC，否则回落 HTTP；
3. 两步都在真机验证过之后，才删服务端那段窗口枚举。

## 4.6 退出协议（防误关）

```
页面「退出大屏」→ 服务写 <data>/exit-request.flag → PostMessage(WM_CLOSE)
                                                 ↓
壳收到 CloseRequested → 有标记 → 真退出（杀 pythonw → app.exit）
                     → 无标记 → 收进托盘（Alt+F4/误触，不退出）
```

这条协议替掉了"看门狗每 20 秒检查、没窗口就拉起来"——旧机制正是 2.55「关闭后反复跳出」的根因。
