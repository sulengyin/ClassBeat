# 01 · 方案总览

## 1.1 要解决的问题

现状（v0.3.24，已验证可跑）不是"功能不够"，而是**壳层架构**导致的三个硬缺口：

| 现象 | 代码证据 |
|---|---|
| 点安装包弹出黑底 PowerShell | `tools/build_installer.py`：`Progress="no"` + `ExecuteFile="powershell.exe"` + `install.ps1` |
| 设置 → 应用里找不到、没法卸载 | `tools/launcher/install-autostart.ps1` 注释明写"不动注册表"；全仓库无 `Uninstall` 键写入 |
| 大屏窗口不属于自己，只能"猜" | `tools/launcher/win-titles.ps1`（130 行）按标题找窗口；`server/rhythm_server.py` 里 `_visible_windows / find_kiosk_windows / screen_minimize / screen_exit` 靠枚举窗口干活 |

链路上跑着四个**不属于本项目**的进程：`7zSD.sfx` → `powershell install.ps1` → `powershell watchdog.ps1`（常驻，每 20 秒扫标题）→ `powershell start-kiosk.ps1` → `Chrome --kiosk` + `pythonw`。

后果：`docs/PLAN.md` 里"看门狗"出现 31 次、"kiosk" 17 次，2.51（换版要重启）、2.55（关闭后反复跳出）、2.58（跨代自愈）全是壳层补丁。

## 1.2 目标形态

**一个进程拥有窗口、服务和安装生命周期；业务代码一行不改。**

```
classbeat.exe（Tauri 2 主进程，签名）
├── WebView2 窗口        http://127.0.0.1:<port>/screen  （全屏 · 无边框 · 置顶）
├── pythonw 子进程       resources/server/rhythm_server.py（隐藏窗口，壳守护）
├── 托盘                 打开大屏 / 手机页 / 检查更新 / 重启服务 / 日志 / 退出
├── 单实例互斥体         第二次双击 → 聚焦已有大屏
├── 防休眠               SetThreadExecutionState
└── 自启                 HKCU Run + --autostart（延迟 8 秒）
```

安装产物：`ClassBeat_<ver>_x64-setup.exe`（NSIS，perUser）+ `ClassBeat_<ver>_x64.msi`（perMachine，学校批量）。

## 1.3 三个不可让步的约束

1. **用户不需要装任何运行时**（ROADMAP 第 1 条）。→ 0.4.x 内置 `python-embed`（11MB，**0.5.0 已移除**：
   服务换成 Rust 二进制，安装包 10.87 MiB → 2.43 MiB），WebView2 依赖系统自带。
2. **教室是触控一体机，每天关机**。→ 冷启动到全屏就绪目标 ≤20 秒；自启必须可靠。
3. **老师的数据不能丢**。→ 程序与数据物理分离；卸载默认保留数据；覆盖安装先备份再迁移。

## 1.4 范围

**做**：壳（窗口/托盘/热键/自启/防休眠/单实例/守护）、安装·注册·卸载、旧版迁移、签名更新链路、验收。

**不做**（明确写进 PR 描述，避免范围蔓延）：

- ❌ 不改业务逻辑（`app/` 9783 行 JS、`server/` 1561 行 Python 保持行为不变）
- ❌ 不做账号体系 / 云同步 / 多班管理（ROADMAP P4 单独排期）
- ❌ 不做 macOS / Linux / Android 大屏
- ❌ 不迁服务到 Rust（留给下一版，决策门在验收 D 跑通后）
- ❌ 不删旧的 `tools/launcher/`、`tools/installer/`（保留以便复现 0.3.x）

## 1.5 最关键的一个技术判断

老师配置存在浏览器 `localStorage`（origin 隔离），换壳 = 换 origin。
**但这不构成阻塞**：`app/backup.js` 每 10 秒把整份配置 POST 到服务端
`backups/config/rhythm-<日期>.json`，且已有"origin 变了就静默恢复最新快照"的机制。
所以新壳首启会自动接管老师的数据。

→ 这条必须在真机验证一次（验收 C4），不能只信代码。
