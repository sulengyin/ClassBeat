# 06 · 验收清单

每条都是"怎么测 / 看什么 / 算不算过"。**P0 不过就别开工**。

## P0 · 现场探测（教室机 1 台，5 分钟）

```powershell
# 系统版本（Win7 / Win10 1803 以下 → Tauri 路线不成立）
[System.Environment]::OSVersion.Version

# WebView2 运行时（有 pv 值 = 可用）
Get-ItemProperty 'HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}' | Select pv
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}' | Select pv

# 管理员权限（决定 perUser / perMachine 默认值）
([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole('Administrators')

# 8765 占用
netstat -ano | findstr :8765
```

**通过**：OS ≥ Win10 1803 且 `pv` 有值（≥100.x）。
`pv` 为空 → 安装包换 `offlineInstaller`，或该机走旧 kiosk 分支。

## 验收 A · 安装

| # | 步骤 | 通过条件 |
|---|---|---|
| A1 | 干净机双击 setup.exe | 图形向导；**全程无黑底控制台窗口** |
| A2 | 安装中看任务管理器 | 无 `conhost.exe`；`powershell.exe` 最多一个且无窗口（清场用），装完即退 |
| A3 | 完成页勾"启动" | 10~20 秒内大屏全屏出现，之前无白页/404 |
| A4 | 设置 → 应用 | 有 `ClassBeat`、图标、版本、发布者、大小 |
| A5 | `reg query "HKCU\...\App Paths\classbeat.exe"` | 有默认值与 `Path` |
| A6 | `reg query "HKCU\...\Run" /v ClassBeat` | 值为 `"<路径>\classbeat.exe" --autostart` |
| A7 | 开始菜单搜 ClassBeat | 能搜到并启动 |
| A8 | 桌面图标 | 存在，双击进大屏 |
| A9 | `setup.exe /S` | 退出码 0，无人值守完成 |

## 验收 B · 卸载

| # | 步骤 | 通过条件 |
|---|---|---|
| B1 | 设置 → 应用 → 卸载 | 出现向导，问"是否一并删除班级数据" |
| B2 | 选保留 | `%APPDATA%\ClassBeat\data` 仍在 |

| B5 | 任务管理器 | 无 `classbeat.exe`、无残留 `classbeat-server.exe`（0.4.x 时期这里是查 `pythonw.exe`） |
| B6 | 重装 | 首启后屏上是老师自己的班（不是示例班） |
| B7 | `uninstall.exe /S` | 静默卸载，默认保留数据 |

## 验收 C · 从 0.3.24 覆盖安装

| # | 步骤 | 通过条件 |
|---|---|---|
| C1 | 旧版正常跑着（大屏 + 看门狗）直接装新版 | 旧窗口消失，装完只有一个新大屏 |
| C2 | `%LOCALAPPDATA%\ClassBeat` | 已不存在 |
| C3 | 屏上内容 | 班名、课表、岗位、文案与旧版一致 |
| C4 | 手机扫码发一条 | 屏上出现（端口可能顺延，二维码里是新地址） |
| C5 | 任务管理器 | 没有 `watchdog.ps1` / `start-kiosk.ps1` |

C3 失败时先查 `%APPDATA%\ClassBeat\backups\config\` 有没有 `rhythm-<日期>.json`：
有 = 快照在、页面没恢复；没有 = 迁移没跑，查安装日志。

## 验收 D · 日常运行（教室跑一周）

| # | 场景 | 通过条件 |
|---|---|---|
| D1 | 每天关机后开机 | 20 秒内大屏就绪，托盘有图标 |
| D2 | Alt+F4 / 误触关闭 | 收进托盘，点"打开大屏"立刻回来（不再自己乱弹） |
| D3 | `Ctrl+Alt+M` | 最小化；再点任务栏回来 |
| D4 | `Ctrl+Alt+Q` → 确认 | 应用退出、端口释放、托盘图标消失 |
| D5 | 强杀 `classbeat.exe` | 40 秒内自动回来（壳被杀只能靠计划任务/自启拉，`accept` 不测这一项） |
| D6 | 强杀 `classbeat-server.exe` | 25 秒内服务重启、页面自动重连（SSE 恢复）；0.5.0 实测 16.5 s |
| D7 | 拔网线再插回 | 大屏照常；手机可达恢复 |
| D8 | 连续 3 天 | 日志不超 1MB×2；内存无持续上涨 |

## 验收 E · 更新

| # | 步骤 | 通过条件 |
|---|---|---|
| E1 | 托盘 → 检查更新 | 有新版时中文确认框（版本 + 说明） |

## 一票否决

1. 安装或运行中出现任何控制台窗口 → 不通过（本次第一目标）。
2. 卸载无条件删掉 `%APPDATA%\ClassBeat` → 不通过。
3. 覆盖安装后出现两个大屏 / 两个服务抢端口 → 不通过。
4. 页面「退出大屏」关不掉，或关了就再也起不来 → 不通过。
5. 老师配置丢失且无备份可恢复 → 不通过。
