# 03 · 安装 · 注册 · 卸载

目标：老师双击一个 exe，看到图形向导（不是黑窗）；装完在"设置 → 应用"里看得见、能卸；
学校 IT 能用 MSI/静默参数批量部署。

## 3.1 三种产物

| 产物 | 场景 | 关键配置 |
|---|---|---|
| `ClassBeat_<ver>_x64-setup.exe`（NSIS） | 老师自己装，**默认路线** | `installMode: "currentUser"`，免管理员，装到 `%LOCALAPPDATA%\Programs\ClassBeat` |
| `ClassBeat_<ver>_x64.msi`（WiX） | 学校组策略/联管平台批量 | perMachine，装到 `Program Files`，需提权才能写防火墙规则 |
| 便携 zip（可选，后续） | 无权限机器兜底 | 不写注册表，只解压即用 |

## 3.2 `tauri.conf.json` 关键段

```json
{
  "productName": "ClassBeat",
  "version": "0.4.0",
  "identifier": "cn.classbeat.app",
  "build": { "frontendDist": "../web" },
  "app": { "windows": [], "withGlobalTauri": false, "security": { "csp": null } },
  "bundle": {
    "active": true,
    "targets": ["nsis", "msi"],
    "icon": ["icons/classbeat.ico"],
    "resources": ["resources/**/*"],
    "createUpdaterArtifacts": false,
    "windows": {
      "webviewInstallMode": { "type": "downloadBootstrapper", "silent": true },
      "nsis": {
        "installMode": "currentUser",
        "languages": ["SimpChinese"],
        "displayLanguageSelector": false,
        "installerHooks": "installer/hooks.nsh"
      },
      "wix": { "language": "zh-CN" }
    }
  }
}
```

要点：

- `app.windows: []` —— 一个窗口都不预设，全部等 `/api/ping` 通了再创建，避免白页/404 闪现。
- `frontendDist: "../web"` 只是占位与错误页，真正的界面由本地服务提供（保证 origin 与旧版一致）。
- `webviewInstallMode`：
  - 有网机器 → `downloadBootstrapper`（安装时静默下载，最小包体）
  - 教室断网 → 换 `offlineInstaller`（安装包 +127MB，只在检测到缺失时装）
  - 想完全自治 → `fixedRuntime`（+180MB，永不随 Edge 更新）
- `createUpdaterArtifacts` 在配好签名私钥后再改 `true`（否则构建因缺密钥失败）。

## 3.3 系统注册：五个面（旧版一个都没有）

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ClassBeat
    DisplayName / DisplayVersion / Publisher / DisplayIcon / InstallLocation
    UninstallString / QuietUninstallString / EstimatedSize / InstallDate
    NoModify=1 / NoRepair=1 / URLInfoAbout
    ↑ 这一项由 Tauri 的 NSIS 模板自动写，不要手写，否则版本/大小对不上

HKCU\Software\Microsoft\Windows\CurrentVersion\App Paths\classbeat.exe
    (Default) = "<INSTDIR>\classbeat.exe"
    Path      = "<INSTDIR>"

HKCU\Software\Microsoft\Windows\CurrentVersion\Run
    ClassBeat = "\"<INSTDIR>\classbeat.exe\" --autostart"

HKCU\Software\Classes\classbeat
    (Default) = "URL:ClassBeat Protocol"
    "URL Protocol" = ""
    \shell\open\command\(Default) = "\"<INSTDIR>\classbeat.exe\" \"%1\""

开始菜单：由 Tauri 创建
桌面：CreateShortCut "$DESKTOP\ClassBeat.lnk" "<INSTDIR>\classbeat.exe"
防火墙：netsh advfirewall firewall add rule name="ClassBeat" dir=in action=allow
        program="<INSTDIR>\classbeat.exe" protocol=tcp localport=8765 profile=private
        （仅提权安装时写；perUser 写不进去，首次点"手机控制"系统会问一次）
```

## 3.4 安装器钩子（`installer/hooks.nsh`）

Tauri 的 NSIS 模板提供四个插入点，按下面的职责填：

### `NSIS_HOOK_PREINSTALL`

1. **停旧版**：把 `installer/stop-legacy.ps1` 用 `File` 解到 `$TEMP`，用
   `nsExec::ExecToStack 'powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File ...'` 执行。
   `nsExec` 不创建窗口 —— 用户看不到任何控制台。
2. **搬数据**：`%LOCALAPPDATA%\ClassBeat\data|backups|update-source.txt` → `%APPDATA%\ClassBeat\`，
   **目标已存在就跳过**（绝不覆盖老师现用的数据）。
3. **删旧目录**：`RMDir /r "%LOCALAPPDATA%\ClassBeat"`（不删会两份服务抢 8765）。
4. **删旧自启**：`$SMSTARTUP\ClassBeat.lnk`、`$SMSTARTUP\班级节律屏.lnk`、桌面同名 `.lnk`。

### `NSIS_HOOK_POSTINSTALL`

写 App Paths、Run、`classbeat://`、桌面图标；用 `net session` 退出码判断是否提权，提权才写防火墙规则。

### `NSIS_HOOK_PREUNINSTALL`

1. **问数据去留**（`IfSilent` 跳过，默认保留）：
   `MessageBox MB_YESNO|MB_DEFBUTTON2 "要把班级数据一起删掉吗？…"` → 记到 `$8`。
2. 停进程（同 PREINSTALL 的清场脚本）。
3. 删：Run 值、App Paths 键、`Software\Classes\classbeat`、防火墙规则、`schtasks /Delete`（ClassBeat / ClassBeatWatchdog）。
4. 删快捷方式（桌面 + 启动文件夹）。
5. 按 `$8` 决定 `RMDir /r "%APPDATA%\ClassBeat"` 或保留并写日志。

### `NSIS_HOOK_POSTUNINSTALL`

兜底再删一次 Run 值（Tauri 删文件被占用时可能中断前面的步骤）。

### 钩子写法约束

- **不要用 LogicLib 的 `${If}`**：模板不保证 include 了 LogicLib，用 `StrCmp $1 "0" 0 label` 跳转。
- 每一步失败都不要阻断安装（老师装不上比装得不完美更糟），但要写进 `$TEMP\classbeat-install.log`。
- 日志文件路径固定，安装/卸载各一份，老师只需要发这一个文件。

## 3.5 旧版清场脚本（`installer/stop-legacy.ps1`）

**不能** `taskkill /IM pythonw.exe`（会杀掉老师自己开的 Python）。按命令行路径精确匹配：

```powershell
# 只处理名字在这几个里的进程，且命令行包含 LegacyDir 或 InstallDir（小写比较）
$_.Name -in @('classbeat.exe','pythonw.exe','python.exe','powershell.exe','pwsh.exe') -and
(($_.CommandLine.ToLower().Contains($legacyDir.ToLower())) -or ...)
```

顺序：先写 `tools\launcher\stop.flag`（0.3.14+ 的看门狗认这个，能优雅退），
等 1.5 秒再 `Stop-Process -Force`。全程写 `%TEMP%\classbeat-stop-legacy.log`。

## 3.6 卸载流程（用户视角）

```
设置 → 应用 → ClassBeat → 卸载
 → "要把班级数据一起删掉吗？"（默认「否」）
 → 停进程 → 删注册面 → 删快捷方式 → 删程序目录 + WebView2 用户数据
 → 完成页：数据保留位置提示（保留时）
```

静默：`uninstall.exe /S`（保留数据）；`setup.exe /S`（装到默认目录）。

## 3.7 签名与信任

| 项 | 要求 |
|---|---|
| Authenticode | OV 起步（约 ¥1~2k/年），EV 更好；`signtool` 加 RFC3161 时间戳 |
| 签什么 | `classbeat.exe`、`uninstall.exe`、`setup.exe`、`.msi` |
| 杀软预扫 | 发布前过 Microsoft Defender / 360 / 火绒 各一遍 |
| 更新包签名 | 另一套：minisign 公钥进 `tauri.conf.json`，私钥只在 CI secret |
| 未签名的后果 | "未知发布者" + SmartScreen 拦截，一体机上的信任成本很高 |
