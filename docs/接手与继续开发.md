## 2. 三分钟跑起来

### 只想看大屏

```bash
git clone https://github.com/sulengyin/ClassBeat.git && cd ClassBeat
python3 tools/bundle.py --data sample     # 用示例班级生成 app/data.js
start app\index.html                      # macOS 用 open app/index.html
```

`app/index.html` 也可以直接双击打开。页面里没有数据，必须先 bundle 一次。

### 跑一遍校验

```bash
node tools/test_dom.js        # 365 项：页面起得来、控件在、文案不串
node tools/test_rhythm.js     # 97 项：节律引擎
node tools/test_clock.js      # 11 项：北京时间与校时
npx playwright test           # 94 条端到端，覆盖大屏 / 手机页 / 编辑态
python3 tools/check_bundle_parity.py   # data.js 两套实现逐字节比对（要 Rust 工具）
```

e2e 需要一个跑着的 `classbeat-server`。`playwright.config.js` 会自己起它，
但**二进制得先编出来**，否则报"找不到 classbeat-server"：

```bash
cargo build --release --manifest-path desktop/server-rs/Cargo.toml
npx playwright test
```

其余还有 `tools/test_store.js`、`tools/test_setup.js`、`tools/test_backup.js`、
`tools/test_engine.js`（与 Python 参考实现逐日对拍 132 天）、`tools/check_p1.py`、
`tools/test_calendar.py`。完整清单见 `README.md` 的「想验证一切正常」。

### 改桌面版

前置：Rust 1.77+、Node 18+、WebView2（Win10 1803 以上通常自带）。一条命令出安装包：

```
desktop\scripts\build_windows.ps1
```

它依次做：编 `classbeat-tools` → 编 `classbeat-server` → `verify` 自检 → `stage` 装配资源
→ 再 `verify` → `tauri build`（NSIS，带 minisign 签名）。产物在
`desktop/src-tauri/target/release/bundle/nsis/`。

## 3. 发一版怎么做

1. **三处版本号一起改**：`desktop/src-tauri/tauri.conf.json`、三个 `desktop/*/Cargo.toml`、
   界面版本 `app/version.js`（后者对应 `CHANGELOG.md` 的标题）。
   两个版本号含义不同：安装包版本看 Releases 标签，界面版本看更新面板里括号那一位。
2. **补 `CHANGELOG.md`**。它是更新面板文案的**唯一来源**：
   `classbeat-tools make-latest --notes-file CHANGELOG.md` 会取第一节、去掉 Markdown 记号、
   条目用「；」连接、超过 200 字在最近的「；」处截断。所以按"老师能感知到什么"写，
   内部重构不列。
3. **打 tag 并推**（`v0.5.3`）。`release.yml` 会出安装包、`.sig`、`latest.json` 与单文件版
   `classbeat-版本号-single.html`，一起挂到 Release。
4. **前提**：仓库 secrets 里必须有 `TAURI_SIGNING_PRIVATE_KEY` 与
   `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`。缺了 workflow 第 3 步就报错停下——这是有意的，
   没有私钥签不出可自更新的包。当前这两个 secret 尚未配置，历次发版都靠本机私钥手工出包、
   再 `gh release upload` 补齐资产。**别把私钥写进仓库。**

## 4. 目录与语言分工

| 目录 | 是什么 | 语言 |
|---|---|---|
| `app/` | 大屏页面本体（不含任何班级数据） | 原生 JS + CSS |
| `app/engine/` | 节律引擎：按作息表 + 课表现算"现在该干什么" | 原生 JS |
| `app/subjects.js` | 科目词典（同义写法归并）——向导识别、课务下拉、准备清单共用这一份 | 原生 JS |
| `server/` | 手机页静态资源（`phone.html`、`sw.js`、图标） | HTML / JS |
| `desktop/server-rs/` | 局域网服务 `classbeat-server.exe` | Rust |
| `desktop/src-tauri/` | 窗口 / 托盘 / 单实例 / 自启 / 更新器 | Rust + Tauri |
| `desktop/tools-rs/` | 装配、自检、验收、更新清单、单文件打包 | Rust |
| `tools/` | 校验脚本；`bundle.py` 是 `data.js` 的**参考实现** | JS / Python |
| `sample/` | 示例班级（化名），公开仓库用这份 | JSON |
| `data/`、`assets/` | 真实班级数据 —— **不入库** | JSON |

原则：**老师机器上只允许两种语言** —— Rust（壳、服务、工具）与 JS（页面、引擎）。
Python 只留在 CI 与开发机，当"尺子"（参考实现 + golden 数据），不随安装包发出去。
完整判定标准与逐组件理由见 `desktop/docs/13`。

## 6. 八条红线

1. **真实数据不入库。** `data/`、`assets/`、`backups/`、`server/messages.json`、
   `server/net.json` 都在 `.gitignore` 里，因为里面有真实学生姓名、教师姓名与班级名。
   公开仓库只用 `sample/` 的化名数据。改 `.gitignore` 之前先想清楚这一条。
2. **别把老形态捡回来。** zip + pythonw + PowerShell 看门狗 + 页面内自下载更新器
   已在 `79cd068` 退役。它的问题不是"做得不够好"，而是**壳层架构**错位：
   窗口、服务、安装三件生命周期的事分属三个不属于本项目的进程。
   论证见 `desktop/docs/01` §1.1。
3. **时间不许用本地时间字符串直接比大小。** 踩过一次：`until="00:05"` 与 `now="23:55"`
   做 `>=` 比较，跨零点当场判"已过期"，大屏把刚发的通知藏起来。
   现在前后端同一套规则（`app/remote.js` 的 `noticeExpired`），有 6 条断言守着。
   任何涉及"几点到几点"的新逻辑，先想跨零点。
4. **入口越少越好。** 同一件事只留一条路：发版只走 tag + `release.yml`；出包只走
   `build_windows.ps1`；资源装配只走 `classbeat-tools stage`。多一条路就多一处会漂。
   这条对**数据**同样成立：一个岗位"今天归谁"只有一个入口（`resolvePeople`），
   一个科目名只有一份词典（`app/subjects.js`）。2026-11-23 那两条真机故障
   （岗位选了人还显示"待定"、换科目带不出老师）都是这条被破坏的后果——
   症状离根因很远，很难从"待定"联想到"人员解析的 if 顺序"（13.9d）。
5. **别删仓库根的 `update.json`。** 它不是老形态的残留，是**给还在 0.3.x 的机器看的
   跨代公告**：那些机器的服务端会去拉 `main/update.json`，文件不在就报"连不上更新服务器"，
   把版本问题说成网络问题。2026-11-22 退役老形态时把它一起删了，结果就是这个后果（13.9c）。
   内容也别改成"可升级"的清单——0.3.x 装不了安装包，只会在下载校验处失败。
   什么时候能删：确认全网已经没人跑 0.3.x 之后。
6. **一个实体只能有一种内部表示，脏数据在写入口洗完。** 「人」在这上面栽得最重：
   同一个人有 5 种写法（`"张三"` / `{name}` / `{id,name}` / `"s01"` / `"name:张三"`），
   于是全项目长出 5 份 `nameOf`；更麻烦的是写入口不设防——脏数据进得去、导得出、
   导不回（`exportAll` 原样吐，`importAll` 又拿元素级条件整份拒绝），而清洗函数排在
   判死之后，永远轮不到执行。现在三条写路径（`patchConfig` / `patchDayOverride` /
   `importAll`）共用一道写闸门，**先清洗、再只查骨架**。加新字段前先问三件事：
   它属于哪个实体？这个实体有没有唯一表示？写入口在哪？（13.9e）
7. **指路必须指向一条走得通的路；界面能说清的，别用文字补。** 2026-11-23 的三条真机
   反馈是同一个毛病的三个面。换人面板写"没有这个人，去 ⋯ 菜单 → 配置班级补录"，
   而那条路上名册为空时那块直接 `return`，连录入框都不渲染；名单是「人」的主数据，
   却挂在「从岗位表导入」的第①块里，要点六层。另一面是拿文字补界面的欠账：按钮语义
   不清就加一句说明，状态看不见再加一句，最后弹窗里就是整段 60~105 字的说明——
   老师一眼扫过去只会跳过，然后照样点错。规矩：**任何一个"去某处做某事"的提示，
   必须当场把那条路走一遍**，走不通就在原地给动作（"把「张三」加进名单"）；
   **按钮文字、状态、图标能说清的不写句子**，实在要解释的收进「?」——
   注意一体机没有悬停，`title` 在那儿永远不会出现，必须是"点开"。
   2026-11-23：名单升为向导第二步；换人面板引入 `view` 状态（current / group / search），
   组的"按下去"样子与「已带入」才第一次可见（13.9f）。

   **同日的第二轮**说明了这条还没走到底：名单虽然搬到了第二步，但那一页仍是一个
   装整份名单的文本框——只能整份重写，想加三个转来的学生也得把全班抄一遍。
   旁那个「恢复成班级数据里的名单」按钮就是模型错了的证据：它不是功能，是补丁。
   现在改成一人一条、点选 / 全选 / 删除选中 / 输入框加人，改动只在草稿里，
   点保存或下一步时弹**一次**框（+N / −M / 人数变化 / 删的人牵动几个组），
   不加二次确认，也不留兜底路。**入口的形状要贴着老师的动作，不是贴着数据的形状。**
   三条配套规则写进 13.9f：同名即同一人（姓名是全链路唯一键）、比较看人
   不看顺序（顺序变了不算改动）、导入先对比再决定（只多不少直接并，有缺就问）。

8. **更新不能丢用户数据；判断"会不会丢"必须看实测目录，不能读代码猜。**
   2026-11-24 走过一次弯路：真机反馈"每次更新后数据全没、要导 JSON"，第一轮据此
   认定 WebView2 的 localStorage 落在 exe 同级、被 NSIS 覆盖安装清掉，于是加了
   `WEBVIEW2_USER_DATA_FOLDER` 和一套迁移代码——**这是错的，那行代码是空操作**。
   实测：数据在 `%LOCALAPPDATA%\cn.classbeat.app\EBWebView`；Tauri 2 在 Windows 上
   强制用 `app_local_data_dir()` 并**显式传给** WebView2（`webview.rs:559`），
   环境变量被忽略。而 `%APPDATA%\ClassBeat\backups\config` 里 11-20 到 11-24 四份
   快照跨越全部更新仍在，11-22 与 11-24 逐键比对只差 `schemaVersion`——**数据一直没丢**。
   规矩：**WebView2 目录由 Tauri 固定，别用环境变量改**；真要换只能用
   `WebviewWindowBuilder::data_directory()`，且所有窗口一致。桌面端的持久化靠三样：
   固定的 LocalAppData 目录、`%APPDATA%\ClassBeat` 下的每日快照、卸载时不动数据。
   「导入 / 导出 JSON」只服务换电脑迁移，不作为更新后的恢复手段。
