# 使用：大屏自动恢复（页面被误关后自己回来）

> 适用场景：移动黑板蹭到大屏，页面 / 窗口被关掉，但机器还开着。
> 这套工具做两件事：**把页面用全屏方式打开**，以及**页面没了就自动再打开**。
> 它不能阻止别人主动关机、断电或按 Alt+F4，也不改任何系统设置。

## 一、文件在哪

都在 `tools\launcher\` 里：

| 文件 | 作用 |
|---|---|
| `start-kiosk.ps1` | 启动器：没服务就起服务，再用 Chrome / Edge 全屏打开页面 |
| `start-kiosk.cmd` | 给双击用的入口 |
| `watchdog.ps1` | 看门狗：发现页面没了，自动再拉起来 |
| `install-autostart.ps1` | 安装 / 卸载开机自启（可选） |
| `launcher.log` | 启动器日志（运行后才会出现） |
| `watchdog.log` | 看门狗日志（运行后才会出现） |

## 二、第一次用：启动

1. 双击 `tools\launcher\start-kiosk.cmd`（或在文件夹里右键 `start-kiosk.ps1` →「使用 PowerShell 运行」）。
2. 它会先检查本地服务有没有在跑；没有就自己起一个。
3. 服务就绪后，用 Chrome（没有就用 Edge）全屏打开大屏页面。

看到全屏页面出现，就说明成功了。

如果双击后一闪而过，双击同目录的 `launcher.log` 看最后几行，常见原因：

- **没有找到 Python**：这台机器既没有项目自带运行时，也没装 Python 3。
- **端口被占用**：8765 被别的软件占了。日志里会写占用它的进程名和 PID，先关掉那个软件再试。
- **没有找到 Chrome 或 Edge**：先装一个浏览器。

## 三、让它在开机后自己守着我（可选）

`install-autostart.ps1` 只在**当前用户**的启动文件夹里放一个快捷方式，不需要管理员权限，不动注册表。

它自启的是**看门狗**（`watchdog.ps1`），不是启动器：看门狗常驻后会在需要时自己调用启动器，这样页面被关掉才会自动回来。

- 安装：右键 `install-autostart.ps1` →「使用 PowerShell 运行」，看清它打印的路径（启动文件夹、快捷方式完整路径、目标脚本）后输入 `y` 确认。
- 卸载：

  ```powershell
  powershell -ExecutionPolicy Bypass -File "<tools\launcher 的完整路径>\install-autostart.ps1" -Remove
  ```

- 只想看它会写到哪里、不真的写：加 `-DryRun`。

## 四、确认它在跑

看三样：

1. **屏幕**：页面是全屏的，没有地址栏、标签页和关闭按钮。
2. **日志**：`tools\launcher\launcher.log` 最后几行有「服务就绪」「已发出 kiosk 启动命令」。
3. **看门狗**：`tools\launcher\watchdog.log` 里有「看门狗启动」和「页面存在」。

看门狗怎么判断页面还在：看浏览器窗口标题里有没有「班级节律屏」（kiosk 下标题仍是网页标题）；标题拿不到时，再查浏览器命令行里有没有同时含 `--kiosk` 和 `127.0.0.1:8765`。偶发一次没看到不算数，**连续两次**都看不到才会重启，避免误判。

## 五、临时停掉自动恢复

老师或维护人员需要临时关页面（比如要操作桌面）时：

1. 打开 `tools\launcher\` 文件夹。
2. 新建一个空文本文件，改名成 **`stop.flag`**（注意去掉 `.txt` 后缀）。
3. 看门狗下一轮就会看到它，写一条日志后正常退出，并把这个标记删掉。

之后再想恢复自动恢复：重新双击 `start-kiosk.cmd` 把页面打开，再运行一次看门狗（装了开机自启的话，注销重登也会自动起来）。看门狗的命令是：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<tools\launcher 的完整路径>\watchdog.ps1"
```

## 六、看日志

- 启动器：`tools\launcher\launcher.log`
- 看门狗：`tools\launcher\watchdog.log`
- 服务自身输出：`tools\launcher\server.out.log`、`server.err.log`

日志都带时间戳，超过约 512 KB 会自动改名为 `.old`，不会无限增长。

## 七、边界（请务必知道）

- **只能恢复「页面被关掉」**，不能阻止别人主动关机、拔电、按显示器电源。
- **kiosk 模式下照样能按 Alt+F4 关掉**，所以看门狗是必要的，不能只靠全屏。
- 看门狗检测到**锁屏、注销、关机中**时不会拉起页面，避免和系统关机抢。
- 页面关掉不影响本地服务和手机通知（服务是独立进程）。
- 看门狗一分钟内最多重启 3 次；超过会暂停 5 分钟再继续，避免反复弹窗。

## 八、要不要配合诊断

如果页面仍然频繁被关，先按 `docs\诊断-页面被误触关闭.md` 跑一次只读诊断，把结果发回，再决定是改手势设置、加挡块，还是只依赖自动恢复。
